# 🛒 Minha Lista de Compras

Um aplicativo desenvolvido com **React Native, Expo e TypeScript** para organizar produtos que precisam ser comprados de forma simples e prática.

## 📌 Sobre o projeto

O **Minha Lista de Compras** permite adicionar produtos, definir suas quantidades e remover itens da lista quando necessário. O projeto possui uma interface simples e organizada, facilitando o gerenciamento das compras do dia a dia.

## ✨ Funcionalidades

- ➕ **Adicionar produtos:** informe o nome e a quantidade do produto.
- 🗑️ **Remover produtos:** exclua itens da lista facilmente.
- 📋 **Visualizar a lista:** veja os produtos cadastrados e suas respectivas quantidades.
- 🧺 **Estado vazio:** mensagem exibida quando não há produtos na lista.
- 🔢 **Contagem de itens:** acompanhe a quantidade de produtos cadastrados.
- 📱 **Interface responsiva:** desenvolvido com React Native, permitindo execução em diferentes plataformas compatíveis.

## 🛠️ Tecnologias utilizadas

- **React Native** — criação da interface do aplicativo.
- **Expo** — desenvolvimento e execução do projeto.
- **React** — gerenciamento dos componentes e estados.
- **TypeScript** — tipagem e organização do código.
- **JavaScript** — lógica de funcionamento da aplicação.

## ⚙️ Como executar o projeto

### 1. Pré-requisitos

Antes de começar, instale:

- [Node.js](https://nodejs.org/)
- [Visual Studio Code](https://code.visualstudio.com/)

### 2. Clone o repositório

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pelo endereço do seu repositório no GitHub.

### 3. Entre na pasta do projeto

```bash
cd lista-de-compras
```

### 4. Instale as dependências

```bash
npm install
```

### 5. Execute o aplicativo

```bash
npm start
```

Para executar diretamente no navegador:

```bash
npm run web
```

## 🧠 Conceitos aplicados

Durante o desenvolvimento, foram utilizados conceitos importantes de programação, como:

- Componentização e reutilização de código.
- Gerenciamento de estado com `useState`.
- Passagem de propriedades entre componentes (*props*).
- Manipulação de listas com `FlatList`.
- Validação de campos de formulário.
- Tipagem de dados com TypeScript.
